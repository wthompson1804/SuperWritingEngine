# Drop box: listings you find yourself

1. Found a place you like on any site (Zillow, Trulia, StreetEasy, Zumper, Craigslist, a building's own site)? In your browser choose **File → Save Page As…**, pick **"Webpage, Complete"** (or "HTML only"), and save it into this `inbox` folder.
2. Or print the page to PDF (**File → Print → Save as PDF**) and save the PDF here, or drop a screenshot here.
3. Or paste the listing's web address into `links.txt` in this folder, one per line. Zillow, Trulia and StreetEasy links are never opened by our tools, so for those please save the page instead (step 1).
4. That's it. Each time the listings are updated, every file is read and the apartment is added using only what the page shows; `STATUS.txt` says what was read from each file and what still needs a person.
5. Screenshots: no text reader is installed here yet, so a screenshot is marked "needs reading" and looked at by hand. A saved page or a PDF works best. (Your files stay on this computer; only the listing details are kept in the project.)
